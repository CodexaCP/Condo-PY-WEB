Subir actualizaciones (deploy)
5
Compilar el proyecto
Tu PC
Siempre primero en tu PC. Reemplazá la ruta con la de tu proyecto.
▸ PowerShell — Tu PC
cd "C:\Users\jalvarez\Documents\GitHub\Condo-PY-BACK\Condo.Api"

dotnet publish -c Release -o ./publish
6
Copiar archivos al servidor
Tu PC
Esto se ejecuta desde tu PC, no desde el SSH. El scp se conecta solo.
▸ PowerShell — Tu PC
# Puerto 22 (estándar)
scp -r "C:\...\Condo.Api\publish\." root@2.25.187.20:/opt/condo-py-api/

# Si SSH usa otro puerto (ej: 2222)
scp -r -P 2222 "C:\...\Condo.Api\publish\." root@2.25.187.20:/opt/condo-py-api/
Ojo: en ssh el flag de puerto es -p minúscula, en scp es -P mayúscula.
7
Reiniciar el servicio
Servidor
▸ SSH — Servidor
# Reiniciar
systemctl restart condo-py-api.service

# Verificar que quedó corriendo
systemctl status condo-py-api.service

# Ver logs en tiempo real
journalctl -u condo-py-api.service -f

9
Levantar instancia de prueba en otro puerto
Servidor
Para testear una versión nueva sin bajar la que está en producción:
▸ SSH — Servidor
# Copiá los archivos nuevos a una carpeta separada
cp -r /opt/condo-py-api/ /opt/condo-py-api-test/

# Levantá manualmente en otro puerto (ej: 5099)
ASPNETCORE_URLS=http://0.0.0.0:5099 \
  dotnet /opt/condo-py-api-test/Condo.Api.dll

# Ctrl+C para detenerlo cuando termines
Tip: Mientras prueba en :5099, el servicio oficial en :5071 sigue sin interrupciones.
10
Ver y editar configuración de un servicio
Servidor
▸ SSH — Servidor
# Ver la configuración actual
systemctl cat condo-py-api.service

# Editar (abre nano)
nano /etc/systemd/system/condo-py-api.service

# Después de editar, recargar y reiniciar
systemctl daemon-reload
systemctl restart condo-py-api.service
